# 天气预报课程任务

任务日期：2026-09-18；实现与验证日期：2026-09-29。题目要求的提交日期为 2026-09-24，本次提交保留实际日期。

## 功能与使用

打开名片夹首页，点击「天气预报 · 查看出行天气」。选择省份／地区和城市后自动查询。切换省份将城市重置为该地区第一项。页面展示温度、天气状况、相对湿度、风速、风向、蒲福风级，以及包含今天的七日最高／最低温、天气和降水概率。点击「刷新天气」重新获取。

加载时显示进度和城市名称；无网络、超时、服务异常或响应格式异常时显示中文提示，并可点击「重试」。快速切换城市会取消前一个请求，并用请求序号阻止过期结果覆盖当前城市。离开页面会释放请求资源。

## 结构

- `entry/src/main/ets/pages/Weather.ets`：ArkUI 选择器、展示及页面状态，负责生命周期与过期响应隔离。
- `entry/src/main/ets/service/WeatherService.ets`：NetworkKit HTTPS 请求、连通性检查、超时、状态码、异常与资源释放。
- `entry/src/main/ets/model/Weather.ts`：响应类型、校验、天气代码与风力转换。
- `entry/src/main/ets/model/WeatherCities.ts`：离线省市名称及坐标，覆盖范围见《城市数据》。
- `entry/src/main/module.json5`：声明 INTERNET 和 GET_NETWORK_INFO 权限；无需定位权限。

UI 不直接创建 HTTP 请求。天气查询不读写名片，名片持久化继续保持离线可用。项目未引入第三方依赖。

## 数据接口与限制

使用 [Open-Meteo Forecast API](https://open-meteo.com/en/docs)，HTTPS、无需 API 密钥；仅传递选中城市的坐标和预报参数。时间统一采用 `Asia/Shanghai`。页面明确标记模型估算和数据时间；当前天气来自天气模型，城市或地区代表点网格值与所在地观测可能有差异。

数据归属 [Open-Meteo](https://open-meteo.com/)，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；免费接口用于非商业课程演示，商用前应核对服务条款及额度。接口可达性依赖设备网络与第三方服务。

## 构建及验收

```sh
bash scripts/test.sh
bash scripts/build.sh
```

构建产物位于 `dist/entry-default-unsigned.hap`；安装前通过 DevEco Studio 配置个人签名。不要提交签名文件、证书或密码。

设备验收步骤：

1. 正常联网进入天气页，检查默认城市、温湿度、风力及七行预报，并核对数据时间与单位。
2. 切换省份，确认城市列表同步更新、旧城市数据清空；选择非省会城市，确认查询对象正确。
3. 连续快速选择多个城市，最终结果应只属于最后选定城市。
4. 断网进入页面，应显示网络提示和重试；恢复网络点击重试，应恢复数据。
5. 网络连接正常但无法访问服务时，确认超时／服务失败提示及重试入口。
6. 加载中返回名片夹，再进入天气页；页面应可以重新加载，原名片仍存在。
7. 小屏设备滚动至最后一日，检查温度、降水概率、来源说明完整可见。
