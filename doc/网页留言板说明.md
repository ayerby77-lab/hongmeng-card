# 网页留言板 · 2026-09-27 课程任务

实现日期：2026-09-29；要求提交日期：2026-10-07。首页点击“网页留言板 · 留下相遇的回声”进入。

## 要求与实现

| 作业要求 | 实现位置与行为 |
| --- | --- |
| Web 加载 rawfile 本地 HTML | `entry/src/main/ets/pages/MessageBoard.ets` 使用 `$rawfile('message-board.html')` |
| 结构、样式、脚本在网页侧 | `entry/src/main/resources/rawfile/message-board.html` 单文件，无网络依赖 |
| javaScriptProxy 注入原生对象 | `NativeBoard` 仅公开 `submitMessage`、`showToast` |
| 原生持久化 | `store/MessageStore.ets` 保存到应用私有目录 `messages.json` |
| 原生主动调用网页函数 | `runJavaScript` 调用 `MessageBoard.renderMessages` 和 `MessageBoard.notify` |
| 打开页面恢复历史 | 初始化读取文件，`onPageEnd` 回传历史留言 |
| 主动通知 | 原生工具栏“推送原生通知”更新网页通知区 |
| 加载与失败提示 | 进度条、加载文案、15 秒超时、主文档错误、存储异常和重试 |
| 独立桥接封装 | `bridge/MessageBridge.ets` 负责校验、保存与回调，页面负责 Web 生命周期 |
| 特色功能 | 网页标题同步原生标题栏、刷新、字数提示、空状态、离线使用 |

## 通信协议

网页 → 原生：

```js
const result = JSON.parse(window.NativeBoard.submitMessage('张三', '今天很开心'));
// { ok: true, error: '' }，或 { ok: false, error: '具体错误' }
window.NativeBoard.showToast('来自网页的问候');
```

原生 → 网页：

```js
window.MessageBoard.renderMessages([{id:'uuid',name:'张三',content:'今天很开心',createdAt:1790000000000}]);
window.MessageBoard.notify('原生通知内容');
```

原生使用 `pageCall` 将数据 JSON 序列化后构造固定方法调用，转义 U+2028/U+2029。网页使用 `textContent` 显示用户文本；特殊字符与 HTML 标签作为文本展示。桥接方法白名单、仅允许本地页面导航和 CSP 限制共同缩小桥接访问范围。当前页面专用于可信本地内容；添加在线页面时应使用独立且不注入桥接的 Web 容器。

昵称 1–30 字、正文 1–500 字，长度按 JavaScript UTF-16 单元计算，网页与原生均校验。总量上限 500 条，到达上限明确提示；已有留言完整保留。网页收到历史数据后才启用提交，提交成功后清空正文，失败保留输入。

## 持久化和职责

`MessageStore` 沿用名片存储的临时文件 → 完整写入 → fsync → 关闭 → rename 方案。新数据先落盘再更新桥接内存并通知网页。磁盘失败时保留旧文件和旧内存；文件损坏时阻止提交并保留原文件供排查。展示或 Toast 失败不会将已经成功落盘的提交报告为失败。

存储、桥接、模型校验与页面分别封装，无新增依赖。同步文件操作限定在课程规模（500 条）；后续更大数据量可迁移异步存储。留言仅保存在当前设备，卸载或清除应用数据会删除文件。

## 验收步骤

1. 从首页打开留言板，查看加载状态、空状态以及原生标题“相遇留言板”。
2. 填写昵称与中文留言，点击保存：出现原生 Toast、列表新增留言、正文清空。
3. 输入空白、超长文本：应提示输入限制；原生接口也执行独立校验。
4. 添加引号、换行、emoji、`<img src=x onerror=alert(1)>`：内容原样展示。
5. 点击“体验原生 Toast”，确认原生提示；点击原生“推送原生通知”，确认网页通知区更新。
6. 刷新、返回再进入、终止进程再启动：留言顺序和内容保留。
7. 关闭网络后打开留言板并提交，功能保持可用。
8. 调试构建临时改为不存在的 rawfile：应显示加载错误或超时和重试；恢复路径后重新构建。
9. 调试环境将私有 `messages.json` 改为损坏 JSON：页面显示读取错误，原文件保留，提交受阻；修复文件后重试恢复。
10. 检查窄屏、键盘弹出后的滚动、系统返回和多次刷新。设备专项验证状态见《网页留言板验证记录》。
