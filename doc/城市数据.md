# 省市与查询坐标

天气页面使用 `entry/src/main/ets/model/WeatherCities.ts` 的离线静态列表，提供 34 个省级地区、392 个城市／地区的两级选择。城市列表包含地级市、自治州、地区、盟，以及数据源中的省直辖市、县与新区；直辖市、香港和澳门分别提供一个代表查询点。台湾包含数据源收录的市、县。

## 数据来源

- 发布方：和风天气（QWeather）官方 [LocationList 仓库](https://github.com/qwd/LocationList)。
- 原始文件：[China-City-List-latest.csv](https://github.com/qwd/LocationList/blob/master/China-City-List-latest.csv)。
- 本次快照：`China-City-List v202506200`；获取日期：2026-09-29。
- 数据字段：`Adm1_Name_ZH`、`Adm2_Name_ZH`、`Location_Name_ZH`、`Latitude`、`Longitude`。保留来源信息；天气接口请求直接使用经纬度，本项目未使用和风天气 API 或 Location ID。

## 生成与维护规则

按 `Adm1_Name_ZH` 生成省级项，再按 `Adm2_Name_ZH` 去重生成城市／地区项。优先选取与行政区名称相同或省略“市”字的记录；其余地区使用源列表中的首个代表地点。宜兰县、新竹县和云林县分别显式选取宜兰市、竹北市和斗六市，以提升代表性。经纬度保留源文件的数值，未运行额外地理编码请求。

这些坐标用于天气网格查询，是城市或行政区的代表点；大型地区的天气可随地点、海拔明显变化。列表覆盖范围以这一静态快照为准。新增行政区或调整名称时，应核对新版来源并更新此文件；应用运行时无需下载城市列表，也无需定位权限。

校验项：省级项数为 34；每个省至少一个城市；同一省内城市名唯一；经纬度为有限数值，纬度在 [-90, 90]、经度在 [-180, 180] 内。
