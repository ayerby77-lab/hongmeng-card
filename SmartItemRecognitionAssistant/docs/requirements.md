# 项目开发清单

依据《实验三 智能物品识别助手APP》整理。以下业务功能均待实现。

- [ ] 相机拍照、实时预览、前后摄像头切换、相册选图。
- [ ] onnxruntime-ohos 集成及官方 yolov13n.onnx 加载。
- [ ] letterbox、归一化、NCHW 转换及比例/padding 记录。
- [ ] 输出解析、NMS、检测框原图坐标还原、置信度阈值调整。
- [ ] TaskPool 异步推理，防抖或串行排队。
- [ ] 预处理/推理/后处理耗时，以及同步/异步界面响应对比。
- [ ] 检测框、类别、置信度展示及分类计数。
- [ ] 修正类别、删除误检项。
- [ ] RDB 保存缩略图、物品清单、识别时间；按时间和类别查询。
- [ ] 设备标识与密钥换取 JWT，Bearer 鉴权、自动刷新、401 响应。
- [ ] 启动检查模型版本，下载并替换模型。
- [ ] 批量上传、recordId 幂等、本地待传队列、联网自动重传。
- [ ] 云端历史与统计，时间/类别筛选及分页。
- [ ] 统一接口错误码及关键流程验证。
