# 工程交接说明

此包从原目录 AnatomyLearning 创建，是可继续开发的源码快照。

## 接收者准备

- DevEco Studio 与匹配的 HarmonyOS SDK。
- 可运行的模拟器或开发设备；安装运行时自行配置调试签名。
- 工程全路径避免空格和中文。
- 真实云端问答需要接收者自己的模型服务、云端配置与密钥；部署说明以实际云平台运行环境为准，云函数尚未完成真实部署验证。

## 打包内容与排除项

包含源码、离线模型资源、文档和测试；排除 Git 元数据、IDE 配置、缓存、构建输出、本机 SDK 路径以及签名凭据。压缩包内部顶层为 AnatomyLearning，可直接作为 DevEco 工程打开。

本包提供源码；接收者构建后安装运行。未提供已签名的通用安装包。

## 最小检查流程

1. 打开工程并同步 SDK，完成构建。
2. 配置签名，在模拟器启动首页。
3. 查看人体模型，测试搜索、点选、详情、收藏与历史。
4. 查看课程资料，新增资料后进行问答并打开引用原文。
5. 验证意图冷启动、热启动、重复请求及异常重试。

## 验证限制

自动化测试包含替身环境，与真实模拟器和云服务测试分开记录。历史文档中的路径是作者开发环境记录；接收者使用当前解压目录。完整功能是否通过，以接收者或主工程师的实际端到端验收为准。
